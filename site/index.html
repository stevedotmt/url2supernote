url2supernote

Send a link to your Telegram bot; a clean EPUB of the article appears on your Supernote.

What it does

url2supernote is open-source software that fetches a web article, extracts the readable text and images, and packs them into an EPUB tuned for e-ink. The EPUB is saved to a folder in your Google Drive. Your Supernote already syncs with Google Drive, so the article shows up on the device a few moments later, ready to read offline. 

Telegram ──link──▶ url2supernote ──EPUB──▶ Google Drive /Supernote/INBOX ──sync──▶ Supernote

Self-hosted, one person per deployment

There is no shared service and no accounts. Each person runs their own copy, with their own Telegram bot and their own Google Cloud OAuth client, so Google Drive credentials never pass through anyone else's server. The author of url2supernote does not operate a service that receives your data.

Why it asks for Google access

To place EPUB files in your Drive, url2supernote asks for one Google OAuth scope: https://www.googleapis.com/auth/drive.file. During setup you choose a single folder, normally the Supernote's INBOX, in the Google Picker. With this scope the app can:

  • add EPUB files to the folder you picked;
  • check whether a file with the same name already exists in that folder, so an article is never delivered twice.

It cannot read, list, change or delete any other file in your Drive. It also refuses to start if given a token with broader access.

How the app handles that access is described in the privacy policy.

Set it up

Step-by-step guides for creating the Telegram bot, authorizing Google Drive and deploying, either on Google Cloud Run or anywhere Docker runs, are in the project README.
